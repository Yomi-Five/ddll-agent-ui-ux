# 表格设计规则

适用于新建、复刻、恢复、合并及修改表格的结构、样式、组件和交互设计；只读分析保持源稿只读。创建与批量修改按 [表格创建执行方案](table-creation-workflow.md) 推进，筛选装配细则见 [筛选栏布局](tables-filters.md)。局部任务只读取受影响规则，不因此扩展为整页重建。

本文件集中维护表格设计规则；现行硬性要求、通用默认与指定来源的适用边界分别写明，不用单次实测替代全局规范。

## 来源、现行要求与适用范围

- 分开记录指定源稿的实测事实、当前生效的用户要求及尚未证实的行为。实际出稿沿适用源结构并执行现行要求；不能由 AI 自选「纯源稿」模式绕过硬性规则。具体属性的豁免须有用户明确授权，不能扩大到整表或其他页面。
- 源模板按实际端、版本、结构和维护状态选择，不凭业务名称或组件使用次数判断。页面与额外完整展示可能有密度差异，母组件默认值也可能被业务实例覆盖；先读实际目标及其来源，不用其中一份自动统一其他版本。
- 源稿中发现溢出、空白、复制残留名称或样式不一致时，区分版本差异、有效覆盖与缺陷；不把异常采样为新标准，也不据此擅自修复无关历史稿。范围内的真实冲突查明不了时只暂停依赖项，继续独立工作。
- 提取只到实例外层时，不声称格内文案、分段字体或颜色已精确验证；需展开代表性实际实例及必要状态并解析样式。清单、结构读取、样式解析、截图和运行交互分别报告覆盖范围，不把画板数当表格数或抽样当全量验收。
- 本引用只收录可跨项目复用的规范。具体页面、源节点、组件 key、实测数值、业务文案、数据与异常清单留所属任务，不将一次取样固化为所有库的标准。

## 绘制前的最小表格契约

在既有任务记录中锁定以下关系；简单局部修改仅核受影响项，不另设审批、不要求用户填写可自行查明的资料。

| 对象 | 必须确定的属性 |
|---|---|
| 来源与边界 | 实际模板、适用版本、允许变化、必须保留、用户明确例外 |
| 列 | 准确字段与单位、顺序、固定／档位／Fill、最小宽度、表头与数据对齐、内容类型、固定侧、可选／默认可见／权限 |
| 表头与行组 | 叶子列、分组跨度、跨层关系、逻辑记录与物理行、合并范围、层级与默认展开状态 |
| 格内内容 | 实际字体及绑定、颜色、行高、分段范围、各段下划线／链接、多行顺序、换行／省略／裁剪与内边距 |
| 汇总 | 统计范围、业务层级、最终视觉角色、位置、标签／数字／增长率分别的样式、点击能力、口径来源 |
| 筛选与表尾 | 字段、默认值、生效条件、必要操作、完整分页组件、结果总量、每页条数、统计说明与导出关系 |
| 状态与适配 | 有来源的触发和结果、视口与完整网格宽度关系、父子布局约束、要求宽度、内容高度与滚动边界 |

## 按结构选型与画法

以下结构可以组合，不按业务名称强制归入单一类型。先确认行列模型，再复用结构相同的适用模板；所需密度、尺寸和样式均读所属库及业务实例，不预设全表统一行高。

| 结构类型 | 画法与必须保留的关系 |
|---|---|
| 普通明细 | 一条逻辑记录对应来源定义的行；完整表头与可复用数据行共享列配置，必要分页沿完整组件 |
| 横向宽表 | 分离页面视口与全列网格，保留逐列宽和固定边界；不把全部列压进窄视口、不删不可见列 |
| 多层分组表头 | 先定义叶子列，再组合父分组；父宽等于所含叶子列宽和，跨层字段用一个真实跨层格，整体维护表头 |
| 跨行合并 | 一个共享格对应右侧物理行组，共享格高等于覆盖行高和；不重复共享值后隐藏文字、不用相邻小格假合并 |
| 单格多指标矩阵 | 多项内容仍属同一字段时，用业务单元格／Slot承载各段及其对齐，不新增列或贯穿格内的网格线 |
| 多物理行指标 | 同一对象的金额、比例等若在来源中分物理行，保留各行及共享字段跨行；不误改成单格左右双指标 |
| 树形展开 | 区分父行、子行、叶子和汇总；沿真实展开能力、方向与实例缩进，子项显隐后核关联高度和表尾衔接 |
| 多模块报表 | 独立标题、统计口径及表结构作为模块维护，共用筛选按来源保留；模块间距和标题至表格间距分开配置 |
| 连续综合报表 | 一个表头与共享网格贯穿分类段，分类标题／汇总仍属于表内；不按分类拆卡片、加重复表头或模块空隙 |
| 异动／复合记录 | 先确定一次操作与关联对象的关系；保留信息分组、编号链接、多行与标签等实际类型，按内容同步整条记录高度 |
| 周期汇总 | 沿有限周期、截止日期、表内汇总及说明；不擅补周期行或追加明细分页，比率和均值不作简单求和 |

## 表格固定规则

以下是用户明确的通用要求，在本轮授权的表格范围内执行，优先于旧稿对应属性和下文默认值；用户后续明确例外除外。不据此扩改无关历史稿。

- **只额外展示一份完整表格**：每张业务表格在所属画板下额外展示一份不裁剪的完整表格，已有则复用，只保留一份；不再按分页拆出末页等额外展示。完整展示保留本轮确认数据的全部列和内容，行粒度及数据范围沿业务来源，不为展示伪造数据或穷举数据组合。清理重复展示前核独有内容与依赖，完整展示不能替代整页框架。
- **序号列固定 52px**：用于逐行编号的序号／序列号列固定为 52px，表头、全部数据行及完整表展示一致，不随 Fill／Hug 拉伸；无此列时不自行新增，接待单号等业务编号不因含数字套用此宽度。
- **表格与分页器间距为 0**：表格末行外边界或既定固定滚动视口底边，紧贴完整分页组件外边界。衔接父容器 gap 为 0，清除两者之间额外的外部 padding、空占位和分散对齐造成的空隙；保留分页组件内部规范 padding，不以负间距或手移坐标遮盖问题。
- **分页器直接使用组件库组件**：调用所属组件库的完整分页组件实例，通过已有属性、变体及 Slots 承载内容并保留关联；不手画、解组、分离、复制散层或另建本地分页组件替代。完整范围包含库中适用的汇总、统计说明、总数、每页条数、页码及操作，不能只取页码按钮。未定位到组件时继续查找实际库与依赖，仍缺失则明确缺口，不以自行拼装冒充库组件。

## 表格组件结构

- 先读所属库的列宽容器、表头、单元格和业务槽能力，使用其现行组件结构，不将某一库的组件名或宽度公式当所有库标准。
- 库支持同列结构复用时，以完整表头行建立业务组合母组件，数据行通过实例和嵌套类型／槽位表达；保留基础库关联，不打散手排。
- 业务组合以每张表的完整表头与可复用单元格／数据行为基本粒度，多层分组表头作为完整表头维护；不为每个字段、示例值或同样式行另建业务母组件。已有库内部拆分保留，不以此规则打散或重构库。
- 业务母组件保留有来源的代表性内容，变化内容通过实例属性／受支持覆盖承载；不以空数据母组件覆盖实际报表，也不将某一实例的金额、门店或日期写回所有实例。切换变体后复核实际内容及覆盖是否保留。
- 库有列宽档位则按适用档位和填充能力使用；用户指定参考列宽时逐列实测并映射目标，不能擅自取整。两者确实冲突时说明契约差异，不任意 resize 或压缩塞入视口。
- 验收核真实母组件／嵌套关联，逐列表头与全部行的顺序、宽度、选择状态及内容。底层单元格仍为实例不证明外层表格复合关系正确。

## 实例覆盖、分段样式与密度

- 组件名称和节点位置不是版本权威。相同 key 可能保留不同历史名称；沿实际主组件、所属库、嵌套、属性、Slots 和覆盖确认能力，不凭名称或频次强制迁移。
- 列宽档位、填充样例宽度与业务实例实宽分别记录。Fill 可产生小数，不能任意取整或重置到母组件默认；保持一套共享列边界，不逐行独立分配或舍入。档位数字不自动等于字数上限。
- 同格／同层混排按实际分段读取和配置字体、颜色、下划线、链接、单位与换行，包含分页统计和 Tooltip。列默认样式不能覆盖已有分段；字体本身的粗斜效果不能用另一字体的字重或倾斜近似替换。
- 文字样式绑定与视觉准确分别验收。源文字无匹配绑定时先查所属库；仍缺失则说明缺口，不能为获得 styleId 替换为不同字体、重建同色样式或宣称全部已绑定。
- 表头、正文与复合行可有不同密度。多行、图片、标签、输入等沿适用业务类型和内容高度，同条记录的其他格同步适配；不只拉高背景而文本偏顶，也不将全部内容压回普通单行。
- 表格对齐按字段和格内结构决定。独立数值列按下文规则；复合格或既有矩阵有明确左右分布／居中关系时保留该关系，不按「包含数字」全局右对齐。表头字段与模块标题分别匹配样式。
- 最终汇总的视觉角色须按本轮确认范围逐项声明，包含模块最终合计、合计列和行列交点；不能仅凭「合计」字样或层级名称判断。标签、数值、增长率与可点击能力分别配置，不整行刷色。

## 内容、分页与行粒度

- 随内容展示的表格用适合的 Hug 纵向容器；明确纵向滚动视口保留其固定高度，不一律改 Hug。分页组件调用及零间距衔接按 [表格固定规则](#表格固定规则) 执行。
- 增删／隐藏行后读末行底边、视口底边和分页组件顶边，核实际外部间距为 0，排除空洞、意外裁切及额外内边距；不手移分页或填空白框补高度。
- 按本轮实际需要覆盖行数增减与长列表，不为测试制造无关状态。截图核末行衔接，根框无重叠不代表内部衔接正确。
- 一行代表什么、是否跨行合并、共享值归属及计数口径按业务来源，不凭重复值猜。多状态能在同表不同行表达时集中展示，不逐状态复制整页。
- 先核整张表的标题、字段原文及顺序、单位、分组和合并关系，再配置组件。连续的一张表不因复用方便拆成多张，合并单元格不以两个相邻格模拟；不同业务分类是否分表按来源，不机械拼接。
- 模块间距、标题至表格间距、同表内部间距分开设置；同表内不插入模块级空隙。无更具体来源的新建报表，模块间距默认 32px、标题至表格默认 16px；已有稿按其明确基准保留，不批量套默认值。

## 报表文字、数字与汇总语义

以下作为无更具体来源的新建报表默认；指定现行稿、所属库的明确约束及用户最新例外按主 skill 的来源分工处理，不追改无关旧稿。

| 对象 | 规则 |
|---|---|
| 表格模块标题 | 16px、Medium，绑定匹配的现有文字样式；与表头字段区分，不将整块表头统一改成标题字号 |
| 数字 | 沿指定数字样式及分段绑定，保留精度、符号和单位；编号、日期与数量分别识别，不凭含数字批量套数值字体 |
| 明细与小计 | 文字及数字使用正文黑色；可跳转的小计也保留黑色，不以品牌蓝替代全部链接表达 |
| 总合计 | 仅数字使用蓝色，不论该数字是否可跳转；合计文案保持黑色、Medium。不得把整行或整列统一刷蓝 |
| 增长率 | 保留已确认的涨跌语义色，不被总合计蓝色覆盖；正负对应色以所属库及业务基准为准，不自行推定红涨绿跌 |
| 无数据占位 | 使用短杠 `-`；零值仍显示零，无目标的占位不做链接；整表无结果另按其空状态组件处理 |
| 表头括号与空格 | 表头括号用英文 `()`；不以空格、全角空白或附加数字补对齐，保留有业务含义的原文分隔与单位 |

- 颜色、字重与点击能力分别配置；先判定明细／小计／总合计、标签／数字／增长率及行列交叉位置，再按规则赋值。不能靠名称含“合计”、蓝色或数值格式反推业务语义。
- 文字、数字和颜色绑定现有适用样式／变量；远程共享库绑定有效时不因本地列表为空而重建本地样式。无匹配样式时说明缺口，不擅造样式或覆盖已确认的分段字体。
- 汇总所在区域按来源确定，可能在表内或完整分页区域；不能为统一外观擅自挪位置。末行边线核实际叠边及所属库规则，无要求不额外添加底部分隔线。

## 对齐与操作列

- 金额、价格和数量列右对齐，表头及分行数据沿同一右侧内边距；优先库变体，核实际布局而不只改 Hug 文本对齐。
- 标识符、编号、联系方式和时间不因含数字而当数量。本规则限相应表格列，不推广到表单或所有指标卡。
- 单元格文字、标签、按钮、图文和多行内容在格内垂直居中，合并格与被其他格撑高的行同样核验；保持适用的对称 padding，不以不等内边距顶位置。
- 操作列是否固定、固定图标状态及阴影按该页面类型和来源确认，不把列表规则套所有详情内表格。
- 固定列边界从表头至末行连续，沿源投影层级及参数；背景遮住后方内容，阴影不叠加或被视口误裁。
- 操作组复用完整来源组件，按内容排列，不用 FILL／两端分散强拉按钮。间距读现行稿及变量，不固化某次测值。
- 逐行核操作顺序、状态和条件显隐，不能因组件默认存在就保留不适用操作。

## 视口与完整展示

- 完整表宽由各列及适用间距计算，不将画板视口宽当整表宽；超出时仅在视口裁剪，保留完整列、正确自动布局和来源固定列。
- 每张表格额外的一份完整展示按 [表格固定规则](#表格固定规则) 执行，不以页面有无裁剪决定是否保留；不另建末页展示。
- 页面和唯一完整展示同步修改，核列、数据、状态、序号列宽及组件关联一致；展示数据范围沿本轮确认内容，不把分页总数直接当作需要补画的数据行数。
- 先读表格与裁剪祖先边界，再截图判断实际裁剪；完整展示与相邻内容按完整可见范围留统一间距。

## 长文本与自适应

- 先确认宽度模式：固定列宽的宽表由视口裁剪／横向查看，拉伸矩阵则让真实列网格随内容区填满，业务 Fill 列沿实际分配；不将三者混为同比缩放。指定最小宽、比例或固定列须有依据，表头、数据、合并与汇总同步执行。
- 长文件名／表格文本一行省略，格子裁剪不能越到隔壁列；不以绝对叠层盖住溢出。需要保留二维内容时横滑，不擅自藏列。
- 弹性列与固定列按来源功能确定，最小表宽实测／按规范，不设全局固定数值。常规与适用窄宽逐列检查。
- 表头与正文共享逐列宽度关系；多层表头的父分组宽度等于其子列实际总宽。改列宽同时核全部受影响行、合并格和汇总，不只改当前表头。
- 自适应核完整父子链的固定／Fill／Hug、min／max 尺寸及裁剪；需要填满时让实际内容填充，不只拉宽外框。内容随行数增高的表格不残留限高，明确滚动视口保留来源高度；不把该规则用于取消其他弹窗的限高。

## 交互依据与状态表达

- 区分实际观察到的静态状态、库提供的能力、已有说明／流程和已运行验证的行为。空目标连线、裁剪、排序图标或可展开属性都不能单独证明交互已可运行；交付分别说明外观、能力、标注和原型验证结果。
- 筛选没有查询按钮不等于所有控件立即生效。即时／回车／确认、生效范围和带入参数须有依据；显式生成报表与普通筛选查询分别处理，未生成、空结果和生成中也不能相互替代。
- 字段设置入口不证明内部已有拖拽、重置、固定、选择上限或保存范围。已存在图层但实际隐藏，不自动纳入出稿；库有能力不等于本次需要显示。
- 链接字段先核触发、目标和参数，再沿适用颜色及分段样式；仅需跳转样式时沿用户边界，不新增目标页。返回后的筛选／滚动保留、整行或箭头点击、展开记忆等没有依据时不自行补成规则。
- Tooltip 既核入口和准确内容，也核真实正文宽度、分段、编号、锚点和必要状态。最大宽、延迟、移入保留、移出关闭及视口避让沿来源，不套任意固定值；外框改变后实际文本约束一起核。
- 查询、生成、说明和导出只覆盖旧稿／指定原型或用户明确授权的状态，不为「完整交互」自行补失败、超时或其他异常。导航页签的滚动／联动规则不自动推广到表格横滚或其他浮层。

## 跳转、展开与统计说明

- 从原型的实际触发逻辑核可跳转字段、父行展开及说明入口，不能只看默认截图。入口与必要展开态须在真实页面上下文表达，独立组件样例不能代替业务状态；无来源的状态不扩画。
- 跳转样式与业务颜色规则分别满足；用户只要求跳转样式时不增加目标页或原型连线。保持无权限、空值等已有条件，不把所有编号或金额一律做链接。
- 可展开父行复用库中展开能力和对应方向图标，核收起／展开方向、子行层级和缩进；明细叶子与合计行不因同列批量带入箭头。
- 统计说明同时核准确正文、统计口径、序号格式、触发点及浮层锚点；内容自适应时检查内部文本 maxWidth／高度与实际换行，避免外框变宽但文字仍受旧约束。触发、移入浮层、移出及视口避让按来源表达。
- 用户要求交互标注时使用 Figma 原生标注，写清真实适配及触发规则；静态示例与可运行原型分别报告，不以标注存在声称交互已运行。提示完整核验沿 [提示说明防遗漏](design-error-prevention.md#提示说明防遗漏) 执行。
