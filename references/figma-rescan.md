# 按需刷新来源索引

仅在用户要求刷新、目标失效或当前来源无法定位时使用。扫描结果属于任务／项目资料，不写进本 skill。

- 先界定必要文件夹、文件或模块，优先查询已有链接与直接依赖；不因一处索引失效全量扫描团队。
- 按当前可用官方接口及其文档查询，处理分页、截断和权限边界；不假定旧内部 API、脚本路径或会话接口仍存在。
- 索引记录真实名称、链接、维护角色、端／语言、相关页面及查询时间。区分未访问、无权限、未找到和确认不存在，不用空结果概括全部。
- 文件 key、归属和库来源只取实际返回，不从名称或经验拼接；索引只用于导航，进入编辑前仍最小核实目标。
- 登录由用户完成，使用既有授权；令牌、Cookie、临时凭据不进入索引、日志或 skill。权限不足说明具体范围，不自行切换团队或修改网络配置。
- 保留来源与现有索引有效内容，只更新本轮查证部分。结果及未验证项写所属任务工作区；后续从该记录续做，不另造一份互相冲突的清单。
