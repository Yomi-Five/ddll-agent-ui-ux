# 还原与迁移

适用于按源恢复页面、跨文件复制及定稿回迁。未要求变化的内容与视觉保真；按本轮契约验收，不把历史修复参数当永久规则。

## 定稿回迁：先比缺失再补入

- 对照定稿、来源和目标现有内容，按功能、状态、端／版本／语言列已有、缺失、待判断；同名不证明相同，异名不证明不同。
- 只补缺失到对应主文件的现有模块，不整套搬入、不按需求编号另堆一份展示；来源与目标原内容保留。模块不存在或归属无法定位才确认。
- 局部差异用真实局部状态汇总，独有布局／控件／必要反馈保留，数据与操作历史差异不默认扩成整页。说明仅在确有必要且用户要求的交付语境使用，不强制每处加标题描述。
- 汇总不能代替全部适用页面覆盖。共享变更查其所有本轮页面、语言和尺寸，不只改一张；不扩到无关端和现有版本之外。
- 排版沿目标当前布局和同类分组；缩小外壳时核继承背景、裁剪、安全区、投影、浮层和完整状态，保留实例及原生 Motion，不用截图顶替。
- 按映射逐项核新增已归位、旧内容未受损和独有状态未丢；外壳精简、位置调整等已授权差异单列，不以画板数量相等作为完成证据。

## 还原前的对账契约

- 明确对象、允许变化与必须保留：位置、尺寸、间距、填充及绑定、描边及其布局参与、字体／字重／行高／文本样式、圆角、透明度、显隐、Hug／FILL／固定、对齐、裁剪、最小／最大尺寸。
- 快照包含实例自身及嵌套层的覆盖、实际变体、替换图标、文本分段、图片、主题与变量模式；只存内容或布尔开关不够。
- 对账范围含被替换组件的完整输出及受影响相邻区域；相邻差异说明是否由本轮引起，不借机改无关历史内容。
- 每页单独对应自身来源，不能把上一页位置、居中或对齐直接套用下一页；明确映射后再比较，不只按遍历顺序或 ID 末段匹配。

## 逐层与渲染验证

- 按稳定来源映射比较当前与来源的实际属性、内容和关联；浮点容差根据精度与任务契约确定，不固定某次测值。
- 新建与克隆均核默认字体、文本样式、描边参与布局、裁剪及尺寸约束；同组件同属性不保证更新后外观不变。
- 像素差用于定位差异簇，追到具体节点并说明原因；差占比小不能忽略。已授权差异单列，所有必须保留项通过才能称还原完成，未知项不能称一致。
- 最后一次影响尺寸／字体／布局的操作后重核受影响区域、后续排布和完整边界，再核本机截图。结构读回与截图互补，不互相替代。

## 浮层、嵌套状态与失效组件

- 同用途元素逐项核主组件来源、变体、填充／描边、尺寸、圆角、投影和触发点位置；有依据的场景例外保留，不为“一页一套”抹平差异。
- 复合组件嵌套层的选中／悬浮／禁用、图标交换、透明度及显隐单独比较，外层属性正确不证明内部状态正确。
- 沿父链核浮层实际裁剪；该溢出的位置允许显示，不把表格等必要视口裁剪全关。投影核根层／内容层／实例覆盖，来源是单层时不得重复叠影。
- 克隆变体后检查属性引用并用临时实例验证文案／显隐能力；新增轴同步补值及展示格，保留原状态外观。
- 主动查实际使用的库组件是否失效、被移除或取到旧版本，复用已核结果，不每实例重复导入。直接实例可在授权内切现行对应组件并保留内容；库内嵌套问题回库处理，不能静默打散。
- 导入／属性读取失败先列不能保留的具体能力和影响，说明可行方案；无授权不退化成普通图层。母组件修改、发布、业务引用与同步分别验证。
- 文字先按源设内容及字体，再恢复文本样式并读回；混排逐段处理。不可用字体不自换，沿已有替换授权，否则只暂停依赖部分。

## 失败恢复与交付

- 槽位变动导致深层 ID 失效，从稳定根重新遍历，不手拼 composite ID。失败或超时先读回，确认部分写入再补缺，不假定整体回滚或整批重跑。
- 静态状态、原生动效播放、真实运行交互分别取证；未运行不说已验证实际交互。静态交付的连线清理按主文件执行，明确原型任务才保留连线。
- 各目标分别列实际完成、已知差异、未验证及待发布／同步；局部通过不概括全量一致。用户有效反馈进入当前要求，被推翻旧结论不再当基准。
