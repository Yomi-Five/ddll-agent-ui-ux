# 组件规范规则

适用于创建／修改规范库、组件状态、组件集及示例。官方复刻另读 [来源验收](official-component-reproduction.md)，业务实例见 [业务稿规则](app-pc-rules.md)。

## 对照来源与实际绘制层

- 用户指定特定稿及版本时以该来源为准，不用另一版本覆盖；要求对照官网实现时以官方 live／源码为源，第三方 kit 仅辅证。仅要求分析时不扩改官方或规范库；参考文件只读，编辑落在授权目标。
- 每条示例分别数可见子项、左右附件及弹性空白，不能用相邻项或裁切截图推断缺项。问哪项就实测哪项，父级 padding 正确不证明子级 gap 正确。
- 改完与来源同尺寸、同状态并排比较；自身两档一致、属性存在、数量相等都不代表还原正确。
- 看真实填充、描边、文字、背景与主题解析，不跟变量名字猜颜色；同一属性值可能存在不同实例覆盖。
- 沿所属库文本样式、尺寸和变量；源与库尺度确实冲突时按本轮契约处理并说明差异，不擅自改库档位凑像素，也不默选近似值。
- 文本使用文本语义变量；自建库按既有 `text/*` 语义体系，外部库沿其等价体系，不用颜色原语或死色。绑定须语义正确、值正确且主题可解析，缺口报告。
- 不添加组件用途、结构、用法、描述、说明属性或说明画板；保留自身界面文案及必要组件集组名／行列标注。明确要求组件文档时再写。

## 组件修改优先回库

- 通用样式、结构、状态或动效先沿实际母组件追溯所属库、嵌套子组件、变体及使用范围，不能因链接在业务页就只改实例。
- 说明影响范围，在授权内改母组件及相关状态；专属端或用途不扩散。已有能力能表达则直接调用，单页内容／明确一次性例外才用实例处理。
- 业务自有本地组合母组件确认归属，新需求完整复制到副本后改对应母组件；远程规范库保持远程关联，来源业务文件不回写。
- 不用外置叠层、底层控件仍为实例或批量覆盖掩盖复合母组件问题。修改后验证母组件、相关变体及业务实例实际渲染；只清理本轮同属性临时覆盖，保留业务数据、图标及槽内容。
- 发布由用户操作，发布后核业务实际取得的版本；未发布、未同步、仍依赖临时覆盖分别报告。

## 新样式与属性能力

- 先查现行类型、属性、状态及真实渲染，判断差异是稳定可复用能力，还是单条内容／一次性排版。能跨页面、背景和场景成立的能力优先纳入既有组件，不为每个视觉差异新建一套。
- 补库明确所属组件、计划变体／属性和影响，在授权内执行；只要求判断则报告。保留原类型默认行为，覆盖适用尺寸、状态和主题，不为凑矩阵增加同样外观。
- 变体轴、属性名和定义一致，不留重复组合／缺失值。只有显隐的二值能力优先 BOOLEAN，多值类型或状态用变体轴。
- 属性和变体值用中文，布尔在界面呈开／关；保留已有库内部名字和品牌专名，不为统一中文无关重命名。
- 文案、显隐与插槽必须真实绑定；克隆后读属性引用，用临时实例改文案／显隐确认生效，验证后清除临时对象。只开布尔属性不证明内容已显示，槽内默认附件必须检查。
- 来源或本轮任务需要 Tooltip 行内键盘组时，支持「前文＋键盘组＋后文」，两端可为空，由组件承载，不固定快捷键在末尾或临时散拼；不为无此需要的提示补建该能力。
- 同结构顶栏／底栏隐藏按钮后保持来源规定的高度和对齐，不被 Hug 意外收矮。

## 组件状态

- 状态先核来源存在及是否有实际差异。默认、聚焦／选中、已填／开启、禁用、错误只按真实需要建模，无差异悬浮不单列。
- 聚焦／选中不默认品牌蓝或光晕；按来源用描边、填充等区分。危险／错误用语义危险色，禁用用语义禁用色，不靠整层透明度临时模拟。
- 增加状态时克隆新变体，原档外观不变；名字存在不等于能力已补齐。未填与已填禁用若不同则分别支持，不只换一个底色。
- 新增轴补全已有变体的轴值而保留原外观，更新格子、括号、行列和边界。删状态列同步收起空格，不留空列。

## 组件集格子与标注

本节用于本轮新建或已授权整理的组件规范展示；保留用户指定的其他展示基准，不据此重排未涉及的既有组件集或跨库改版。

- 组件内容、标注层和展示边界分别验收。每组应有的组名、弧形分组括号、行列标签和格线逐项对应；不以标题或虚线格子代替弧形括号。
- 同家族可集中展示，主题预览沿指定参考；移动时保留主组件 ID、组件集边界和实例关联，不把不同职责合成一个组件集，标注随所属组件移动。
- 变体在格内水平垂直居中，不骑线或铺满格。组件随内容 Hug，四边到格线各留 **24**，相邻组件间 **48**；外框也离组件 24。
- 一档一个格，组件集主轴 Hug、靠起点并以间距留格缝；不用固定大框、居中和零间距把变体挤在中间。克隆变体真正并入组件集，清除本轮漂出的重复残留。
- 普通格线用紫色虚线；黑色分隔线只用于按钮组件明确的类型分组，不因尺寸／状态分列就套黑线。
- 分组括号改宽只改变中段长度与右端位置，左右圆角半径和控制点跨度保持，不非等比缩放整条矢量。目标过窄时先调格宽，不压扁圆角；放大检查最窄、最宽及中间档，外框尺寸正确不代表弧线正确。
- 组名、行列名、状态和新建图层用中文；标注统一 Regular，并沿现有常规字重变量绑定，不用 Medium／Bold／Heavy。
- 多套纵排，上一套外框底到下一套组名顶至少 **80**；组名、括号、外框按既有 **12、24、20** 节奏分开。行名仅对应自己那档；名字宽于框则扩展示框，不裁成省略号。
- 截图包含完整组名、弧线、行列标签和外框；属性通过、无重叠不能替代标注完整性验收。只改标注不顺手改组件属性。

## 图标与品牌素材补库

- 从当前同用途实例追真实归属，区分符号图标、完整字标与其他展示形式；授权后按同组风格补齐，不混用途。
- 优先官方矢量素材，按需求保留符号／字标，不擅删品牌内容。完整渲染素材后判断，不能凭裁切缩略图或路径数识别图形。
- 沿同组尺寸、描边、圆角、裁剪、主题和变量；图形大小按真实渲染范围与形状近似参考比较，读四边留白，不把一次比例推广为规范。
- 新增变体真正并入组件集，仅改授权项，保留其他变体；发布后核 key 与业务替换，不能只因外层按钮来源正确就认为图标通过。
