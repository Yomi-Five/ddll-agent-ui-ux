# 表格创建执行方案

适用于表格新建、基于旧稿修改、缺失恢复、合并及同类表格批量修正。纯检查沿用只读边界；局部修改只执行受影响步骤，不机械重建整页。本文件承接主 skill 的范围、来源、文案保护和组件约束；先按 [表格设计规则](table-design-rules.md) 核结构选型、组件、分段样式和交互依据，筛选装配见 [筛选栏布局](tables-filters.md)。

执行顺序：**核来源与交付范围 → 复用完整结构 → 配置组件和内容 → 按功能完成一批 → 合并核对内容、结构与视觉 → 修复并只复查受影响项。** 沿用任务已有记录和有效证据，不增加方案审批、重复台账或逐节点截图。

执行 [表格固定规则](table-design-rules.md#表格固定规则)：每张表格只额外展示一份完整表格，不做末页展示；序号列固定 52px；表格与分页组件外部间距为 0；直接使用所属组件库的完整分页组件。

## 1. 创建前确定完整对象和依据

在任务记录中为每类表格建立「目标区域 → 来源 → 允许变化／必须保留 → 验收依据」。把用户最新纠正及适用例外纳入同一记录，不只保留最初方案。

| 核对对象 | 创建前必须确定 |
|---|---|
| 交付范围 | 是整页、嵌入模块还是独立表格；整页中的导航、页签、筛选、操作区、表格、分页汇总及必要浮层是否均在范围内 |
| 来源分工 | 需求对应业务变化，原型对应字段及交互意图，适用现行稿对应保留内容与视觉基准，所属库对应组件结构和状态；差异按属性判断，不用单一来源覆盖全部维度 |
| 筛选与查询 | 完整字段、顺序、控件类型、选项、默认值、带入条件、查询生效条件及 label 规则；不能只核表格数据使用的日期 |
| 行列与分组 | 表格标题及字段原文、单位、每行的业务含义、字段顺序、显示列与可选列、父子分组、小计／合计、合并单元格及穿透目标；完整原型对账，不按局部截图拼表 |
| 数据与分页 | 目标查询条件、数据来源、展示行数、结果总量、每页条数、页码及汇总范围；区分当前页、全部筛选结果和其他来源口径 |
| 复用与状态 | 整页、表格组合、行、单元格、状态标签、完整分页区域及相关导出状态的实际来源和主组件归属 |

来源缺口先在已知文件、关联页面和组件依赖中定位；不能因当前选区未找到就认定不存在，也不让用户整理可查询事实。仍缺失时只暂停依赖项，说明具体缺口；已授权且依据明确的部分继续执行。

## 2. 先复用完整结构，再做允许的变化

- 有适用旧稿时，复制实际完整对象，再最小修改。整页恢复须核完整画板及其父容器，保留导航、页签、完整筛选、操作区、表格和底部区域；额外的唯一完整表展示不能代替整页交付。
- 复制后先对照来源确认框架、显隐、选中状态、相对位置、尺寸、Slots 和组件关联。框架已经失真时先修复，再派生后续同类页面。
- 另一张报表的框架只有在适用版本、页面类型及保留区域已核实等价时才可复用；复制带来的筛选项、汇总字段、文案和默认值须逐项核对。不能为了容纳新表格删掉旧页原有区域。
- 恢复时分别核「页面结构恢复」和「字段／筛选／数据恢复」。原型能生成数据不代表原页面已恢复；只完成其中一部分时准确标记缺口。

## 3. 按完整组件配置筛选、表格和分页

### 筛选与状态

- label 的文字、字数变体、容器宽度、文字对齐和控件间距分别核对。字数变体匹配实际文案，容器宽度遵循本轮指定基准；不能以切对变体代替统一标签列，也不能按短文案长度擅自缩窄容器。长标签保留完整文案，按来源处理同区对齐，不把某次实测尺寸固化为全局规则。
- 状态优先使用所属库已有的状态组件及正确变体，沿用对应业务语义的颜色和绑定；不能只改普通标签的底色和文字模拟状态，也不能把某个状态的颜色推广到全部状态。
- 组件切换后读回业务文案、显隐、Slots、控件值和嵌套覆盖，防止默认内容回流。修改文字时沿工具约定使用组件属性或受支持覆盖，并核实际写入结果。

### 表格与分页整体

- 复用适用的表格组合及行结构，保留基础库关联。核实际主组件和嵌套关系，不能仅凭底层单元格仍是实例就认定整表复用正确；不为排版方便解组、分离或手排组件。
- 分页以来源定义的**完整分页区域**为单位，逐项核汇总、统计说明、总数、每页条数、页码、跳页及适用操作，不能只取页码按钮。来源中不存在的子项不自行添加。
- 分页直接调用所属组件库的完整组件实例，保留嵌套关联，使用已有属性、变体或 Slots 配置；不自行绘制或新建本地分页组件替代。组件未定位时查实际库与依赖，仍缺失则说明缺口，不将业务拼装称为库组件复用。
- 数据行、总数、每页条数和页码使用同一查询结果及分页口径；空结果等仅检查本轮有依据的状态，不为覆盖检查扩画末页等分页展示。分页组件与表格末行或既定滚动视口外部间距为 0，核实际边缘衔接，不靠绝对坐标补空洞。
- 批量样式修正先区分表头、普通数据、合计列、底部合计行及行列交叉单元格，逐类确定允许变化与例外，再应用范围。状态、颜色与宽度规则按语义匹配，不能只按名称批量刷值。

## 4. 写入数据时保护内容和业务口径

- 编辑前只保存受影响区域必要的字段、筛选、数据、组件属性和渲染依据。替换、删除或合并前先核独有内容、隐藏项和组件依赖，操作后对账保留项；不能把删除重建或整实例重置当作局部修复。
- 数据按已核实来源及查询条件写入；若从原型模型提取，核实际路由、带入条件和返回数据。保留原值、精度、分组及行粒度，人民币币种按主 skill 的明确例外补齐；占位符、零值和空结果须有实际依据，不能用占位覆盖待恢复数据。
- 写入、切换变体、调整列宽或共享业务母组件后，将表头、全部受影响行、汇总与分页一起读回。检查实际列宽及可见内容，排除末列被挤压、文本越界、数据变为默认占位等问题。
- 汇总保留来源统计口径。仅在汇总可由已取得数据计算时对账求和；当前页子集、去重统计、比率或父子小计不能直接相加冒充全部结果。未取得完整数据时不声称全量金额已验证。
- 汇总卡片、表内数据、合计、统计说明和关联导出的口径分别核对；用户改选数据或口径后，在本轮适用对象中同步查差异，不能只替换示例金额而留下相反说明，也不擅自改写无授权的数据。冲突尚未解决时只暂停依赖项，不把相互矛盾的内容报为定稿。
- 需要合并的区域先核分组与共享信息归属，保留独有字段、数据和条件。跨表合并须有用户要求或明确来源依据，不能因字段相似自行合并；同内容因入口或操作步骤不同也不机械复制成多页。

## 5. 布局、说明和关联导出一起收口

- 空状态复用指定来源的组件、对齐方式及高度规则，核真正的内容容器是否居中、自适应或保留既定视口；不能只居中文本而留下父级固定空洞。按「让布局解释」处理辅助说明，不补无依据的底部文案，不删必要业务提示。
- 说明按实际字段或区域归属放置，移动后检查原位置的重复内容及布局衔接。必要统计说明同时核入口、准确正文和有依据的展开方式，不能只留下问号。
- 页内表格与额外的唯一完整表展示同步修改，不再增加末页等分页展示；已有完整展示直接复用。保留完整列宽、正常滚动和固定列规则，序号列表头及全部行均为 52px。
- 本轮涉及导出时，核对应完整抽屉／弹窗、筛选摘要、字段选择、步骤组件及有依据的结果态。不能只对齐中间内容而遗漏步骤或底部操作；具体文字与状态沿其实际来源，不从其他业务随意套用。
- 新版本替代旧组合后，清理授权范围内确认无用的业务母组件、重复展示和空容器。先核跨页引用、嵌套依赖、隐藏内容及必要状态，不能以零直接实例认定无用，也不能删掉仍需保留的悬浮等变体；操作后对账保留的实例关联与内容并整理空洞。未获清理授权时只记录候选，不顺手扩删。

## 6. 按同一版稿件合并验收

验收从原始来源和修改前保留项出发，逐项对照最终稿。已核实且未变化的来源证据复用，最后一次修改影响的证据重新取得；不从生成结果反推应有范围。

| 层面 | 必须取得的证据 |
|---|---|
| 内容 | 完整框架与筛选字段对账；全部受影响行列、分组、文案、必要说明及数据逐项匹配；汇总与分页按各自口径核实 |
| 结构 | 真实主组件／实例及嵌套关联、变体、Slots、显隐、变量或样式绑定、自动布局和裁剪边界读回；确认分页整体来自所属组件库，每张表格只有一份额外完整展示且无末页展示 |
| 视觉 | 完整页面上下文及关键区域正常比例截图；检查源稿样式、状态颜色、表头标记、对齐、溢出、空状态、完整展示及分区边界；实测序号列表头及全部行宽度为 52px，表格／固定视口与分页组件外部间距为 0 |
| 保留与同因范围 | 修改前保留内容未丢失；合并删除没有遗漏独有项；本轮同因页面和已有完整展示均覆盖，用户明确例外未被批量覆盖 |

将以上检查并入当前功能批次的一次集中走查，不额外叠加整轮验收。发现明确问题集中修复，只复查受影响项；组件损坏、数据丢失等会扩散的问题即时处理，失败或中断后先核实际完成状态再续做，避免重复创建或覆盖。

用户纠正表格规则后，更新同一份当前依据，按业务语义追到母组件、受影响实例和已有完整表展示，覆盖本轮同因范围；不只修圈出的单元格，也不越界修改无关历史稿。先核共性应改在母组件还是仅属实例内容，再执行；后续更具体例外优先。验收同时对照原始内容、结构读回和最终正常比例渲染，不能用工具成功、属性正确或概览缩略图替代整表结论。

内容、结构、视觉分别给出结论；来源缺失、仅完成写入、未核全部数据或未检查原筛选时，不能统称「整页完整恢复／全部通过」。交付说明实际改动、影响范围、验证结果与剩余缺口，发布和消费者同步另据证据报告。小改动仍需相应证据，但不因此新增脚本、全文件备份或复杂流程。
