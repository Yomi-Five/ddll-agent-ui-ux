# 筛选栏布局规则

表格类型、组件、文字数字、汇总、适配、分页与交互统一见 [表格设计规则](table-design-rules.md)；创建、恢复和批量修改按 [表格创建执行方案](table-creation-workflow.md) 推进。本文件仅维护筛选装配细则，遵循主 skill 的来源分工和文案保护，不新增查询／重置或其他无来源操作。

## 筛选布局与组件

- 筛选栏右侧说明／按钮先 Hug 占位，左侧 Tab 或筛选用剩余宽并按来源处理溢出；选项不与尾部操作互相压字。
- 筛选复用完整来源布局和控件变体，核标签列、按钮 Hug、换行与控件值；不添加来源没有的查询／重置操作。无更具体基准时筛选按钮间距默认 12px，已有稿的间距及变量绑定按来源保留。
- 字段设置区分可选、默认、当前勾选和权限可见列；不把当前未勾选当系统不存在，也不把所有可选列强加进稿。
- label 的字数变体、容器宽度和与控件间距分别核实；不因短字段擅自缩窄统一标签列，长标签按来源完整展示。
- 复用来源的行／列布局，操作组外层可 Fill 占据剩余空间，内部按钮仍按内容 Hug 并沿来源靠齐；不将外层 Fill 传给所有按钮。
- 只有库明确允许的装配外壳可按其说明解组，内部 label、日期和选择等实例继续保留关联；不推广为解组表格或完整分页组件的授权。
