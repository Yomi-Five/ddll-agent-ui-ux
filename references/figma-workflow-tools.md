# Figma 工具与流程

操作前按本轮需要读取；具体 API、参数、权限和能力以当前工具文档为准，不保存某项目命令、ID 或报错流水。脚本层的字体、布局、克隆、变量和截图细节见 [Plugin API 技术细节](plugin-api-notes.md)。

## 读取、编辑与本机验证的分工

| 操作 | 首选路径 |
|---|---|
| 读结构、查库、建文件、受支持的文件复制 | 官方 MCP；先查实际能力，不假定有旧接口 |
| 新需求设计与既有稿修改、文字写入、编辑中的文件内克隆 | 官方 MCP，按当前官方文档加载适用 skill、建立会话并显式定位目标；新增或需编辑文字统一先用 `Noto Sans SC` |
| 既有稿增量编辑、资源导入／绑定 | 优先具备保真能力的官方 MCP；官方能力不足时，仅用已连接且不影响前台的 Console 后台脚本 |
| 设计／改稿阶段截图 | 官方 MCP，核 `Noto Sans SC` 阶段的内容、视觉与结构；不作为目标字体最终验收 |
| 设计／改稿阶段检查通过后统一换字体及最终字体渲染验收 | Console 后台脚本及节点导出截图，使用已确认目标连接，不截取或操纵用户桌面 |
| 跨文件保真复制 | 优先官方支持的后台复制；不足时核 Console 后台能力，保留关联；两者均不足时记录缺口，不转前台复制粘贴 |

- 所有任务全程静默后台，不自动激活／置前应用或浏览器窗口，不发送前台点击、键盘快捷键，不读取或覆盖系统剪贴板，不自动打开预览或结果窗口。不得为连接、复制、截图、验收或故障恢复自行改走原生 UI／电脑操控；用户另行明确要求前台协助时才按该次范围处理。
- Console 只用 API／插件通道后台读写及节点导出；不修改用户正在使用的选区、视口或页面，不以切页、缩放、滚动到节点或选中节点代替目标定位。操作必须依赖改变前台状态时，记录该项阻塞并继续独立工作。
- Bridge 不是官方设计的前置条件。断开时仅暂停最终换字体、本机渲染验收及确实依赖 Console 的步骤，记录待字体收口；不为中途连接反复打断用户。官方工具不可用时如实记录，不能声称已走官方完成。
- 资源导入／绑定按当前工具实际支持执行，不要求 Console 先连接；读回确认关联及实际效果，不扩大授权或用无关联副本绕过能力缺口。

## 目标、连接与分批调用

- 按 [执行与恢复规则](multi-agent-workflow.md#记录工具与恢复) 核实共享连接与实际目标，不占用用户前台焦点；切文件或恢复后最小核实实际目标。需求设计完成后分批验收，同批内容、视觉与结构合并读回和取证，检查时停止写入该区域。
- 初次、切文件、故障和断点恢复后最小核验文件及页面；调用支持目标 fileKey 时显式传入。同一目标持续有效不每步列连接或重查库。
- key 与归属来自用户链接或实际查询／创建返回，不编造。节点未找到可能是页面、旧子层或参数问题，不直接认定 Bridge 断开。
- 用户已重连先验证连接列表和目标最小读取，区分无连接、路由错、页未切、参数错、权限和超时；确需用户操作才一次说明，不循环要求重连。
- 按页／功能区域批量读写，在当前工具时限内完成，不一条巨型脚本处理全任务，也不每节点截图。适用超时值取当前文档，不固化版本参数。
- 写入失败／超时可能已部分完成，先从稳定根查内容、数量和属性，再补缺。初始化失败不继续依赖未定义结果；一次有针对性恢复后同故障仍在，停止同参数盲试并记录当前状态，继续独立工作。
- 截图失败先核活动文件、页与稳定根，修正后最多再试一次；仍失败如实标未截图验证，不以属性读回补成视觉通过。
- 槽位或实例内部移动后重新从稳定根取节点，动态页面使用当前支持的异步读取；不手拼深层 ID。遇失效子层逐项保护读取，不为绕过报错打散组件。
- 先复用已核实资源，再按需导入；不要因导入慢就用无关联副本。跨工具写入可能有同步延迟，读回确认生效后取证，不重复造节点。
- 本机完成不代表云端已保存；未同步时保持工作可恢复，不关闭／刷新丢弃工作，分别报告编辑、验证和云端状态。

## 字体、默认值与可见差异

- 新需求设计与既有稿修改均指定先用官方云端字体 `Noto Sans SC`，不再自行挑选其他临时字体；先查询或验证该 family、所需字重及文字覆盖的实际加载能力，不把仅本机安装当成云端可用。不可用时记录具体缺口，不自行换字体或转前台，继续独立工作。临时用字只覆盖本轮目标中新增或需编辑的文字，不改来源、未改文字或共享库字体定义；纯评审保持只读。
- 写文字先加载本阶段实际使用的字体，富文本按段保留；在原任务记录保留必要的节点／文字区间、临时字体与目标字体／字重、文本样式和原绑定的对应关系。目标字体沿用户要求、现行稿及适用库确定；未知时记录缺口，不擅自定义最终字体。不为临时字体改共享样式、变量或打散组件。
- 设计与改稿期间保持 `Noto Sans SC`，合并进行官方读回和截图验收，不每批反复切换字体或等待 Console。设计阶段内容、视觉与结构检查通过、明确问题已修复后，才通过 Console 后台集中恢复目标字体／文本样式及原绑定，核字重、富文本、实例属性与覆盖；不得提前换回目标字体，也不得用只改样式名称或保留临时字体冒充收口。
- 换字体后重核受影响的换行、Hug／FILL 尺寸、行高、截断、长文本和相邻画板边界，修复本轮字体变化造成的问题，再用 Console 后台节点截图验收。Console 不可用时交付已验证的设计阶段结果和准确待换字体范围，标明目标字体及最终布局待验证，不提前报最终完成。
- 云端字体和截图可能回退，本机数据及实际渲染作为字体核验依据。字重读回正常不能否定偏粗观感，继续查绘制层、分段样式、缩放、重叠和文本样式。
- 仅针对必要节点尝试重新加载并恢复同字体，修后对来源同用途文字与本机截图；不把一次技术故障变成所有复制必刷字体的规则，不改无关文字试错。
- 新建／复制检查实际生效的裁剪、描边是否参与布局、尺寸模式、最小／最大约束、字体及文本样式。布局不稳定先解决生效层，再读最终尺寸，不凭属性默认推断。
- 图片 hash 非空不证明素材可见，核真实填充、比例、可见区域和渲染。内容居中按完整可见范围，不只看图片几何。
- 改布局时仅清理本轮失效约束、旧命名及过期批注，不新增说明块；保留无关内容。

## 飞书需求与附件

- 用适用飞书工具先完整正文后 HTML，按当时专用技能的认证和命令处理，不复制历史租户或脚本。
- wiki 链接先解析实际文档，再读分页／截断；正文嵌入文件与知识库子节点分别检查，子节点为空不代表无原型。
- 附件按实际资源类型下载，主动读取可取得资料，不提前让用户重新上传。临时文件按任务需要保存，不留凭据。
- 权限不足、附件不存在和类型／命令错误分别定位，不能凭一个空结果或错误推出文档没有内容。

## 画板排布与重叠验收

1. 列当前批全部独立展示区域及周边既有边界，最终累计覆盖本轮产出；不只抽查根画板。
2. 换算页面绝对坐标，读根及未裁剪可见后代、浮层、菜单、投影和补充展示的完整占用，尊重显隐与裁剪。有意遮罩／弹窗叠放不当画板碰撞。
3. 每行按实际最下边界和统一展示间距排下一行，横向同理；不用预估高度、旧尺寸数组或固定行步长。
4. 字体、换行、Hug、变体、图片或尺寸变化后，受影响几何结论失效；最后写入后重读尺寸，修受影响行及后续排布，Section 容纳完整内容。
5. 最终边界计算和本机总览／边界放大截图都通过才能称无重叠；数值空列表不能否定截图碰撞，尺寸仍变化先解决稳定性。
6. 只修本轮产出的展示位置与容纳尺寸，邻稿作避让依据；断连、超时或范围未覆盖标待验证。

## Section 背景

- Section 是分区容器，不是产品界面，使用已确认灰色，不用白色；沿本文件已有同类灰色及绑定，没有则查已确认来源，不临时自选。
- 创建／复制时显式落实实际填充和绑定，不能保留未核默认白。只改 Section，不把画板、弹窗、卡片底色一起改灰。
- 不嵌套 Section，分区用位置与间距，不加无用说明。验收逐个读本轮 Section 的填充／绑定，截图含分区及白色画板外边界；内部截图不算已核背景。

## 更新记录

- 业务设计文件维护更新记录。新需求文件创建后的第一步是沿来源建立或复制更新记录页，并置于页面列表首位；完成后才能复制业务稿。需求首次进入每个目标文件登记一次。先查重，后续纠错、补状态和改文案不加行或补正文，明确要求补记才改。
- 更新记录置页面列表首位，紧随官方页面分隔线，保留其他页相对顺序；新需求文件及复制后即核。使用当前支持的官方分隔能力，读回实际 divider 状态，不拿画布线或普通命名页顶替。
- 沿当前文件／复制来源的字体、富文本、尺寸、间距和链接表现，复制适合的既有条目，只改必要日期、需求名和实际作者，不硬编码作者或行尺寸。新设计文件新增条目的临时用字沿本文件字体流程，保留目标字体／样式对应关系并纳入最后统一收口，不改原模板与既有条目。
- 新记录链接指向当前需求，改完读富文本链接并核原模板未改；已有条目错字不借机改。新设计登记优先官方 MCP，先完整落实准确内容与链接；最终字体随设计稿通过 Console 后台统一恢复，不因中途无 Console 停下可独立的设计准备。
- 不凭顶层节点数判记录页为空，读取真实行内容。最终截图核新行与相邻样式，并分别报告已登记、已存在或未验证。
