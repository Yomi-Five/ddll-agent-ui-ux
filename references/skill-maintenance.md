# 技能收录与维护

仅在收录、整理或优化技能时读取；普通设计任务无需加载。

## 适用范围与收录边界

**定位：执行型技能。** 在已授权范围内完成读取、复制、修改、验收与交付，而不是仅提供规范建议。

设计相关工作启用本 skill；有指定源稿的还原任务，保留像素契约和既有样式，不用个人口味改稿。纯评审保持只读，已授权设计任务则完成修改与验收。

**本 skill 的所有记录只包含通用规则、习惯与约束。** 主文件、品味、收件箱、references 及导航均适用；允许保存用户明确指定、跨需求长期生效的工作区落点约定；不存具体项目方案、业务文案／状态、实测尺寸、文件与节点 ID、库 key、一次性团队目录／项目路由、历史事故或工具报错流水。具体资料及来源索引留在所属任务工作区，不能换到 reference 继续固化。通用数值习惯与单次测量区分，不把场景例外升级为全局规则。

## 收录与维护

1. 先判断是本次画错、具体业务方案，还是明确可跨项目复用的习惯；局部错误先修，业务结论留任务记录，不自动升为全局禁止。
2. 用户要求收录时，提炼对象、适用条件、执行动作、例外和验收方法；删除项目名称、实例参数及过程叙述。无法合理判断是否全局时才问，已明确范围不反复确认。
3. 在既有对应规则中合并同义项、消除冲突，不只向禁止清单追加；核心约束与读取路由写 SKILL.md，详细执行流程写 design-workflow.md，场景细则写对应引用，品味写 taste，待定通用想法写 inbox。用户明确指定的长期工作区落点约定按收录边界保留，一次性项目路由／来源清单仍留任务记录。
4. 更新后检查全部调用处、链接、优先级和重复口径；确认通用习惯未丢失。简述改到哪里与形成的规则，不把静态校验说成实际设计效果已验证。
5. 保持入口简短；每条细则有明确触发条件，按操作及实际影响取并集。每轮必读入口，同轮复用有效引用；不以去重、摘要或减少读取为由删除约束、降低验收或扩大授权。
