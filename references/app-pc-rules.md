# APP／PC 业务稿通用规则

用于新需求、已有页面迭代、表单、操作组、弹窗与移动图标。来源分工见 [完整核验](live-alignment-verification.md)，工具与展示容器见 [工具流程](figma-workflow-tools.md)。

## 新需求副本与依赖

- 新需求在独立文件编辑，位置固定为「DDLL-项目管理测试 → 测试用项目」，文件名沿需求完整原名；先查现有，续做不重复创建。新文件创建后的第一步按[更新记录](figma-workflow-tools.md#更新记录)建立并置顶更新记录页，再复制业务稿。常规定位与复制属于已授权执行，无需逐项确认。
- 所需来源及上下文由执行者查找和复制，确认目标实际归属后编辑副本，来源只读；不要在无关页面新建整页示意。
- 新文件按[新文件启用组件库](figma-libraries.md#新文件启用组件库)添加／启用本需求所需的全部组件库，确认可调用后再修改业务稿。规范库实例保留远程关联。业务自有的本地母组件、嵌套依赖与实例一并带入，方便在副本修改；不把规范库组件变成本地库，也不把未展示母组件当无关稿删掉。
- 保留变量、主题、文本样式、富文本、图片与实例覆盖；复制后读回并用最终本机渲染对照来源。依赖不可解析或复制不能保真时说明缺口，不静默降级。
- 默认静态交付，清除副本演示交互及流程起点；明确要求可点击原型时才保留，并核跨文件目标指向正确副本。

## 范围与展示去重

- 有实际设计变化的页面及必要状态才进入新需求展示；仅改入口顺序、禁用条件，不自动重画内部旧流程。
- 在对应原画板副本迭代。仅数据、数量、操作历史或同结构提示不同，不默认复制整页；能在同表不同行或局部汇总表达的就集中表达，独有布局／控件／必要状态保留。
- 以内容、结构与条件判断重复，不凭名字或画板数量删。清理前归回独有浮层／状态并查依赖，清理后核需求覆盖和剩余布局。
- 多端／语言／版本以需求和实时现有稿为准，不自动补齐不存在的整页。文档有明确变化但原型未展开时先查既有承载方式，不能一律漏掉或自行补整套。
- 全局提示按端和场景集中展示；同功能的页面、弹窗及状态相邻，分区靠位置与间距，不在画板外堆解释标题。不嵌套 Section。

## 业务稿间距变量

- 新增／修改自建自动布局的项目间距、生效换行行距和四边 padding 均绑定所属库适用间距变量，生效的 0 也绑定；无效字段不制造覆盖。
- 先查现行稿实际值、绑定与用途，再查已导入及远程变量。用途、解析值和 scope 均匹配才使用；无同用途项时可用同库同值且适用的间距原语，不凭名字相似认定匹配。
- 补绑定保留原值和外观，不四舍五入或改间距凑档；无匹配记录位置和原值，不造变量、不拿颜色或尺寸变量顶替。
- 相对留白用合适的自动布局／padding 表达并绑定，背景素材仍铺满；不声称 x/y 已绑定，不为了绑定挤小图片。画布坐标不当 UI 间距处理。
- 标题行、内容与分页按实际边缘衔接，检查残留固定高、空占位、重复内边距和分散对齐；修造成空隙的布局层，不负间距补洞。
- 验收读引用、解析值与最终几何，覆盖本轮适用尺寸／语言；历史库内部缺口单列，不借补绑定重构母版。

## 操作按钮层级

- 先按同用途现行稿确定角色、顺序和实际样式，区分提交、次要、导航、转化与危险操作；不能因卡片只有一个按钮就改成主按钮。
- 无明确基准时，同一操作组默认一个最右填充主按钮，其余次要；不自行用品牌蓝描边充当次要。明确流程顺序不因视觉习惯擅自更改。
- 移除／删除图标用所属库危险红；禁用用库的禁用颜色，不用整组降低透明度模拟，保留禁用原因及必要提示。
- 优先切换现有变体，核实际绘制层、填充、描边及历史覆盖，不只看属性名。保留文案、尺寸、图标、状态与外层复合关联。
- 同用途操作组保持宽度、对齐和内容间距，不用 FILL 或两端分散强拉文字按钮。核本轮所有适用状态，保留角色例外。

## 表单、条件字段与提示

- 逐字段核 input／select／radio／checkbox／textarea 等控件类型、全部选项、默认值、条件和完整动态文案；克隆不等于控件类型或槽内数量正确。
- 条件字段紧跟触发选项下方，按现行稿层级分组；已有灰底块等结构时复用，位置跟随内容列，不铺满标签列或硬编码坐标。
- 必要辅助说明紧贴对应控件，优先用已有说明槽，与所属内容列对齐；不增加重复解释，不让说明更靠近下一字段。
- 多行表单的标签对内容首行，按同类行实际高度和中心线核验，不将本次测得行高固定为通用值。
- 单选／多选内外文字槽均检查 Hug、最大宽、换行／省略与真实最长文案；只改外层可能仍被内层固定宽裁切。同表单同用途选项间距一致。
- 占位、已填值与禁用值分别使用库语义样式；切变体后重查文字、显隐和属性绑定，不能留下默认占位。
- Tooltip 核入口、完整说明、触发条件和必要展开态，位置随触发点与可用空间处理，不能仅补问号图标。

## 现有布局与整页结构

- 未要求改的文案、单位、空格、字段顺序、导航和卡片结构按指定现行稿保留。原型表达业务意图，不自动提供重新排版授权。
- 新增内容沿同用途完整布局；复合控件复用整体，不只拼底层实例。代码实现以项目已调整的组件为基准，不盲套官网默认。
- 布局更新限任务需要：导航、侧栏和内容按来源关系设置固定／FILL／Hug，不硬编码某产品整页尺寸，也不为小改全页改自动布局。
- 给尾部控件固定占位，正文用剩余宽；卡片宽、字段位置、表格／分页衔接与适用窄屏一起核。子页页头用所属来源的导航方式，不一律替换成标题或面包屑。
- 新旧来源冲突时按职责解决，必要业务限制不能只因旧行放不下而删除；先找现行同类承载，仍有歧义才暂停依赖部分。

## 弹窗、抽屉与浮层

- 所属库有完整弹窗／抽屉组件时，根节点使用完整实例，不能只替换标题或操作区；内容用既有插槽，缺能力先报告，不打散凑结构。
- 含只读对象信息和少量编辑字段的弹窗，按“先确认对象，再填写内容”组织：上方用所属库浅灰语义底色集中承载名称、类型、标识等只读信息，组内标签和值对齐、紧凑排列；下方编辑区独立留白，不强求与只读信息共用横向表单列，也不新增“对象信息”等重复标题。此习惯用于本轮获准新建或调整的同类内容，不扩改无关旧稿。
- 上述弹窗的少量编辑字段采用上方标签、下方输入框；标签简短指向填写动作，有来源明确字段名时保留其语义。百分号等单位优先放在完整输入组件的后缀槽内右侧，不散放框外；必要影响范围说明紧贴输入框下方，用次级文本语义样式降低权重，保留可读性。
- 同类弹窗沿现行宽度与组件规范，内容分组后优先让高度随内容增长，不挤压留白或无依据加宽。内外留白和组内行距形成层级，使用适用变量，不将一次实测尺寸固化为全局值；字段回填、默认值、必填和校验仍按已确认来源，不从视觉示例推导业务变更。
- 宽度与响应规则读该类型现行稿／规范；固定宽按固定宽，响应式按原规则，不一律设某个宽度、窗口边距或缩放比例。
- 遮罩弹窗可独立展示遮罩和本体，外层无页面底色，不复制无关背景页面。无遮罩下拉／Popover／Tooltip 在实际触发控件上下文展示，不能只剩小浮层的大空画板。
- 按实际视觉遮罩判分类，透明点击层不是遮罩。核锚点、箭头、层级、投影、完整可见边界及裁剪，不只看浮层内部。
- 独立展示的弹窗或抽屉实例外套无填充／描边的自动布局画板，保留实例关联；宽高按内容或遮罩用途设置，投影不被裁掉。
- 替换结构后重核内容贴边、内边距与操作区；无法保留的授权目标表现单列差异，不静默改变。移动后的旧子层 ID 失效则从稳定根重取。

## 移动端图标来源

- 只用该界面实际所属移动库图标，先查订阅与真实母组件；不能因同文件订阅桌面库就跨端借图标，也不从其他业务组件中拆图标顶替。
- 搜索真实目录及多种命名方式，并核渲染造型，不以一次名称搜索无结果判缺失。匹配同组尺寸、线宽、网格、变量与实际绘制范围。
- 缺失时按已有授权在所属图标库补齐；发布由用户操作，再验证业务母组件及适用状态。无补库授权则说明缺口，不用 emoji 或近似异风格图标顶替。
- 克隆同类行后换成语义正确图标，核完整行的比例、箭头、间距和状态，不沿用相邻行错误语义。
